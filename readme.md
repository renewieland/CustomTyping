# ローマ字タイピング — 設定ガイド

ゲームの設定は `setting.json` で変更できます。  
書かなかった項目は初期値で動きます。`setting.json` が無くてもゲームは動きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構成 |
| `style.css` | 見た目（テーマ色もここ） |
| `game.js` | ゲームの動き |
| `setting.json` | 設定（このファイルで説明） |
| `words.json` | 出題する言葉 |

## 操作

| キー | 動き |
|---|---|
| `Enter` | スタート／結果画面からもう一回 |
| `Esc` | プレイ中・結果画面からリスタート |

## setting.json の書き方

```json
{
  "title": "タイピング",
  "desc": "高スコアを目指そう！！",
  "theme": "green",
  "time": 90
}
```

- 文字は `"` で囲みます。数字と `true` / `false` は囲みません。
- 項目と項目の間は `,`（カンマ）で区切ります。**最後の項目の後ろには付けません。**
- 改行は `\n` と書きます。

### 画面の文字

| 項目 | 内容 | 初期値 |
|---|---|---|
| `title` | スタート画面のタイトル（ブラウザのタブ名も変わる） | `"ローマ字タイピング"` |
| `desc` | スタート画面の説明文（`\n` で改行） | `"60秒のあいだに、…"` |
| `resultTitle` | 結果画面の見出し | `"おつかれさま！"` |

> `desc` に「60秒」と書いている場合、`time` を変えたときは `desc` も書き換えてください。

### 見た目

| 項目 | 内容 | 初期値 |
|---|---|---|
| `theme` | テーマ色。`"blue"` / `"green"` / `"yellow"` / `"red"` | `"blue"` |
| `background` | 背景画像のファイル名。空欄なら通常の背景 | `""` |
| `font` | Google Fonts のフォント名。空欄なら標準 | `""` |
| `hideRomaji` | `true` でローマ字のガイドを隠す（打った文字だけ表示） | `false` |

- **背景画像**: `index.html` と同じフォルダに画像を置き、`"background": "photo.png"` のようにファイル名を書きます。
- **フォント**: `"font": "Noto Serif JP"` のように、Google Fonts の名前を正確に書きます。名前が違うときやネットに繋がっていないときは、標準のフォントになります。
- **ローマ字を隠す**: 読み仮名が画面に出ないので、漢字の言葉は読みを知っていないと打てません。

### 時間とミス

| 項目 | 内容 | 初期値 |
|---|---|---|
| `time` | 制限時間（秒） | `60` |
| `timeBonus` | 1語打てるごとに足す秒数 | `0` |
| `missTimePenalty` | ミス1回で減らす秒数 | `0` |
| `missScorePenalty` | ミス1回で引く点数（0点より下にはならない） | `0` |
| `maxMiss` | この回数ミスしたら終了。`0` なら無制限 | `0` |

- `timeBonus` で足した時間は、最初の制限時間を超えて増えます。
- `maxMiss` を1以上にすると、プレイ画面に「ミス 2/5」のような表示が出ます。

### スコア

| 項目 | 内容 | 初期値 |
|---|---|---|
| `scorePerLevel` | レベルごとの1語の基本点 | `{ "1": 10, "2": 10, "3": 10, "4": 20 }` |
| `comboBonusEvery` | 何連続ごとにボーナスを付けるか。`0` でボーナスなし | `5` |
| `comboBonus` | そのときに1語へ足す点数 | `5` |

例：初期値では、5連続で1語+5点、10連続で+10点になります。  
ミスをすると連続が0に戻り、ボーナスもなくなります。

### 出題

| 項目 | 内容 | 初期値 |
|---|---|---|
| `easyWords` | 最初の何語を、必ずレベル1〜2から出すか | `4` |
| `recentExclude` | 直近に出た何語を、出ないようにするか | `8` |

連続（ミスなしで打てた語数）が増えるほど、レベルの高い言葉が出やすくなります。

### Xで共有

| 項目 | 内容 | 初期値 |
|---|---|---|
| `shareUrl` | 投稿に付けるページのURL。空欄なら付かない | `""` |
| `shareText` | 投稿の文。`{score}` `{done}` `{accuracy}` `{maxCombo}` が値に置き換わる | `"ローマ字タイピングで{score}点！…"` |

| 書き方 | 入る値 |
|---|---|
| `{score}` | スコア |
| `{done}` | 打てた言葉の数 |
| `{accuracy}` | 正確さ（%） |
| `{maxCombo}` | 最大連続 |

## words.json（言葉の一覧）

レベル1〜4に分けて、`"表示 読み"` の形で書きます。

```json
{
  "levels": {
    "1": [
      "猫 ねこ", "犬 いぬ", "ゲーム"
    ]
  }
}
```

- 表示と読みの間は、半角スペースを1つ入れます。
- 表示と読みが同じ言葉（かなだけの言葉）は、`"ゲーム"` のように1つだけでOKです。
- 読みには、かな・カタカナ・全角の英数字（`ｗ` など）・`！` `？` `、` `。` `…` が使えます。
- `ー` は `-` キー、`…` は `.` を3回で打ちます。
- ローマ字は、読みから自動で複数の打ち方（`shi` / `si`、`nn` / `n`、`xtu` / `ltu` など）が作られます。
- レベルの目安：1 = 2〜3文字、2 = 4〜5文字、3 = 5〜6文字、4 = 9文字以上。
- 1語の中に半角スペースは入れられません（表示と読みの区切りに使うため）。
